# Asset sources

Every third-party file shipped with the game, where it came from, and the terms
it is used under. Anything not listed here is generated by the project's own
code at build time or at runtime.

## Environment

| File | Source | Licence |
| --- | --- | --- |
| `public/assets/env/spruit_sunrise_1k.hdr` | [Poly Haven](https://polyhaven.com/a/spruit_sunrise), distributed via the [three.js](https://github.com/mrdoob/three.js) example assets | CC0 1.0 |

Used for image-based lighting and as the visible sky. It is what gives the
stone its warm bounce light and the gold rings their reflections.

## Stone

| File | Derived from | Licence |
| --- | --- | --- |
| `public/assets/stone/stone_albedo.webp` | `brick_diffuse.jpg`, three.js example textures | see note |
| `public/assets/stone/stone_bump.webp` | `brick_bump.jpg`, three.js example textures | see note |
| `public/assets/stone/stone_roughness.webp` | `brick_roughness.jpg`, three.js example textures | see note |

The albedo is not the original image: it is desaturated, level-adjusted and
re-tinted to weathered limestone so it reads as Maya cut masonry rather than
modern red brick. The bump and roughness maps are the original photographic
surface data, converted to greyscale WebP. The three.js repository is MIT
licensed; these particular texture files carry no separate licence notice in
that repository, so treat their provenance as unverified and replace them if
the project is ever distributed commercially.

## Characters

| File | Source | Licence |
| --- | --- | --- |
| `public/assets/characters/player.glb` | [`-poca-tok-2026`](https://github.com/badbuny126-png/-poca-tok-2026), pinned by commit and checked by SHA-1 in `scripts/prepare-assets.mjs` | unstated by the source repository |
| `public/assets/characters/locomotion.glb` | Idle / Walk / Run clips extracted from `Soldier.glb` in the three.js example assets | see note |
| `public/assets/characters/skin_balam.webp` | generated by `tools/bake-costume.mjs` | this project |
| `public/assets/characters/skin_kuk.webp` | generated by `tools/bake-costume.mjs` | this project |

`locomotion.glb` contains **only** animation curves and the bone hierarchy they
address — no mesh, skin, material or texture from the source model. The clips
are Mixamo-derived. Adobe's Mixamo terms allow use of their animations within a
project but restrict redistributing the assets on their own; they are included
here as part of a game rather than as a standalone animation pack. If that is
not a comfortable basis for your use, delete the file: the game detects its
absence and falls back to the procedural gait in `src/characters.js`.

The two skins are baked by this project from the mesh's own geometry — see
`tools/bake-costume.mjs`. The source mesh ships a 2×2 placeholder texture, so
without them every fighter renders as a flat silhouette.

## Fonts

Cinzel and Nunito are loaded at runtime from Google Fonts (SIL Open Font
License 1.1). No font files are stored in this repository.

## Generated at runtime

The sun-glyph court marking, the ball, the rings, the torches, the crowd, the
power-up gems and every sound in the game are produced in code — see
`src/court.js`, `src/render.js` and `src/audio.js`.
